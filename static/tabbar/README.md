# TabBar 图标说明

## 游戏装备销售数据 Tab 图标

需要为以下5个Tab页面准备图标（未选中和选中状态各一张）：

### 图标规格
- 尺寸: 81px × 81px (推荐)
- 格式: PNG
- 背景: 透明
- 未选中颜色: 灰色 (#7A7E83)
- 选中颜色: 主题色 (#3cc51f 或自定义)

### 所需图标列表

1. **数据概览 (overview)**
   - equipment-overview.png (未选中)
   - equipment-overview-active.png (选中)
   - 图标建议: 📊 柱状图/数据图表

2. **账号管理 (account)**
   - equipment-account.png (未选中)
   - equipment-account-active.png (选中)
   - 图标建议: 👤 用户/账号图标

3. **数据同步 (sync)**
   - equipment-sync.png (未选中)
   - equipment-sync-active.png (选中)
   - 图标建议: 🔄 同步/刷新图标

4. **交易记录 (transactions)**
   - equipment-transactions.png (未选中)
   - equipment-transactions-active.png (选中)
   - 图标建议: 📝 列表/记录图标

5. **饰品库存 (inventory)**
   - equipment-inventory.png (未选中)
   - equipment-inventory-active.png (选中)
   - 图标建议: 🎮 游戏手柄/背包图标

## 临时方案

在正式图标准备好之前，可以使用 iconfont 或 uview-plus 的图标组件作为临时替代。
